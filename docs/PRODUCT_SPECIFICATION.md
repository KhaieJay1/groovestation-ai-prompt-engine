# 📦 PRODUCT SPECIFICATION: GrooveStation Pro
**Version 1.0 (Enterprise Edition)**
**Date**: 2026-01-26

## 1. Executive Summary
**GrooveStation Pro** is an automated, white-label content generation engine designed to scale music video production for YouTube. It allows non-technical operators to launch and manage multiple branded "24/7 Radio" style channels without video editing skills.

**Key Value Proposition**:
*   **Zero-Edit Workflow**: Drag & Drop audio -> Receive 4K Rendered Video.
*   **White Label Architecture**: Fully rebrandable (Logo, Colors, Intro) via a "No-Code" Settings Dashboard.
*   **Enterprise Scale**: Capable of processing unlimited tracks in batch queues.

## 2. Technical Architecture
The application is built on a robust, modular Python stack packaged as a standalone Windows Executable (`.exe`).

*   **Core Engine**: Python 3.13 (Orchestrator Logic).
*   **Frontend**: Flask (Web-Based Local Dashboard) + HTML5/JS.
*   **Rendering**: FFmpeg (High-Performance Video Encoding).
*   **Configuration**: JSON-based dynamic injection (`settings.json`).
*   **Deployment**: PyInstaller (Frozen Binary distribution).

### System Requirements
*   **OS**: Windows 10/11 (64-bit).
*   **Dependencies**: None (Self-contained). *FFmpeg recommended for optimal performance if not bundled.*
*   **Storage**: 500MB (App) + Storage for Output 4K Videos.

## 3. User Manual (Standard Operating Procedure)

### A. Installation
1.  Locate the delivery folder: **`.../frozen-kepler/DISTRIBUTION/`**.
2.  Copy this folder to any location (e.g., Desktop).
3.  Double-click **`GrooveStation_Pro.exe`**.

### B. Configuring a Brand (The "White Label" Feature)
1.  Open the App Dashboard in your browser (`http://localhost:5000` opens automatically).
2.  Navigate to the **⚙️ Settings** Tab.
3.  **Brand Name**: Enter your generic channel name (e.g., "Lofi Lounge").
4.  **Primary Color**: Select a brand color (updates all visualizer bars and text).
5.  **Intro Text**: Customize the 3-step intro sequence (e.g., "Relaxing Vibes" -> "Study Session").
6.  Click **Save**. The entire engine reconfigures instantly.

### C. Production Workflow
1.  **Select Vibe**: Click a Genre Card (e.g., "Deep Focus", "Jazz").
2.  **Ingest**: Drag & Drop MP3 files into the upload zone.
3.  **Process**: The system automatically:
    *   Generates a unique 4K background (or uses assets).
    *   Renders a reactive audio spectrum visualizer.
    *   Overlays the specific Brand typography (Arial Bold Premium Style).
    *   Outputs the final `.mp4` to the `Output_Mixes` folder.
