# GrooveStation Pro (`BussGroove`) — White-Label B2B AI Audio Prompt Engineering & Media Automation SaaS

**Author:** Kayode Joseph Afuvape, CCIBS  
**Architecture:** Full-Stack Multi-Tenant B2B SaaS, Constraint-Driven LLM Prompt Engineering Engine & Standalone Desktop Application  
**Frontend Stack:** Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS v4, Lucide-React, plus Flask HTML5/JS White-Label Designer UI  
**Backend & AI Stack:** Python 3.13, Local Ollama (`llama3.2`), SQLite (`better-sqlite3` & `sqlite3`), YAML/JSON Constraint Schemas (`sound_locks.json`, `prompts.yaml`), `mutagen` ID3 Tagging, FFmpeg 4K Rendering, PyInstaller (`GrooveStation_Pro.exe`)

## 1. Executive Summary & Commercial Problem Statement

In commercial generative AI audio production, **free-text prompting suffers from severe "prompt drift"**—producing inconsistent tempos, unwanted vocal artifacts, and unpredictable instrumentation that fail platform monetization and brand consistency standards.

**GrooveStation Pro** (incubated under the **BussGroove** commercial media brand) solves this by combining:
1. **Sonic Reverse-Engineering & Style Transposition R&D (`SmartSunoGenerator`):** Deconstructs reference tracks into locked structural parameters (**Genre Spine, Exact BPM Band, Musical Key across 12 key variations, Lead Instrumentation, Percussion Groove, Energy Ceiling [1–10], and Vocal Policy**) so any song's structure can be re-engineered and reproduced across **11 commercial genre verticals**.
2. **Constraint-Driven LLM Prompt Guardrails (`SoundLockManager`):** Eliminates free-text prompting by compiling every prompt through a deterministic 6-block schema via local **Ollama (`llama3.2`)** and programmatically stripping forbidden tokens (`vocals`, `heavy distortion`, `EDM drops`) before generation.
3. **Mandatory Minimum Monetization Quality (MMQ $\ge 90\%$) Compliance Gate:** Enforces a pre-rendering quality assurance gate that blocks any audio asset failing sonic consistency ($\ge 90\%$), loop tolerance (30–60 min), or audio clipping checks from entering the 4K FFmpeg rendering pipeline.
4. **White-Label B2B Multi-Brand Architecture:** Allows B2B operators, agencies, and record labels to dynamically switch brand identities (`settings.json` / `sound_locks.json`), typography, color palettes, and 3-tier operator permissions (`CORE`, `ADVANCED`, `PRO`) via a Next.js 16 / React 19 workstation or a standalone PyInstaller Windows executable (`GrooveStation_Pro.exe`).

## 2. System Architecture

```
┌───────────────────────────────────────────────────────────────────────────────────┐
│        NEXT.JS 16 (APP ROUTER) + REACT 19 + TYPESCRIPT WORKSTATION UI             │
│  - `/prompts` | `/styles` | `/inspirations` | `/songs` | `/kpis`                  │
│  - Next.js Server API Routes (`/api/ollama/generate`, `/api/database/*`)          │
└───────────────────────┬───────────────────────────────────────────┬───────────────┘
                        │                                           │
                        ▼                                           ▼
     ┌────────────────────────────────────┐      ┌──────────────────────────────────┐
     │  SOUND LOCK & PROMPT R&D ENGINE    │      │  MMQ COMPLIANCE GATE & 4K RENDER │
     │  (`agent_service.py` / Ollama)     │      │  (`orchestrator.py` / FFmpeg)    │
     │  - 6-Block Deterministic Schema    │      │  - MMQ >= 90% Consistency Gate   │
     │  - BPM / Key / Lead Mutation       │      │  - Automated ID3 (`mutagen`)     │
     │  - Regex Negative-Token Sanitizer  │      │  - 4K/60fps Branded Visualizer   │
     │  - Automated YouTube SEO Generator │      │  - White-Label Brand Switching   │
     └────────────────────────────────────┘      └──────────────────────────────────┘
```

### The 6-Block Deterministic Prompt Architecture
All prompts generated by `SmartSunoGenerator` (`backend-engine/agent_service.py`) and `SoundLockManager` (`backend-engine/sound_lock_manager.py`) enforce a strict, non-negotiable structure:
```text
[CORE GENRE] -> [ENERGY & TEMPO BAND] -> [LOCKED INSTRUMENTATION] -> [MOOD & ATMOSPHERE] -> [STRUCTURE RULES] -> [NEGATIVE CONSTRAINTS]
```

## 5. Quick Start

### 1. Next.js 16 + React 19 Workstation (`frontend-nextjs/`)
```bash
cd frontend-nextjs
npm install
npm run dev
```

### 2. Python Prompt Engine & White-Label Flask Server (`backend-engine/`)
```bash
cd backend-engine
pip install -r requirements.txt
python init_db.py
python app.py
```
Ensure local [Ollama](https://ollama.com/) is running (`ollama serve` with `llama3.2` pulled) to enable live constraint-driven prompt generation and automated YouTube SEO metadata synthesis.
